Visual proposals

Five ways gitspore could look, each built as a live Three.js scene. None is decided. cozy-04 and lab-05 belong to concept v3 (planter grid); bark-01, clay-02 and vine-03 to concept v2 (repo as a living scene).

Shares are measured from the render screenshots, interface included. Sources: aesthetics.md and renders/ in project-management/research/inspiration/.

concept v3 · planter grid · 2026-10-06

One pot per agent

Six pots on a bench, one per agent. A plant wilts while its agent waits for you. The repo moves to a 2D branch graph that opens from a garden map in the scene.

Suggested proportions

Measured: neutrals fill 96–99% of every render. In the full views of bark-01 and clay-02 the data colour stays under 1%, too little to read a repo from a distance. Suggested target (not agreed): neutrals 93–95%, the data colour 3–5%, every other accent at most 1%, with larger beads and stronger veins when zoomed out.

Method: each screenshot scaled to 320×180. Pixels with saturation above 0.4 and value above 0.3 count by hue (red/coral, amber, cyan; for v3 also green, blue, pink); all others count as neutral, split by luminance (dark below 0.12, light above 0.5). Interface panels are part of the image.
