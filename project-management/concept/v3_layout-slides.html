The rules

Three settings make every state

Side panel

  • Agents, Issues, Branches, or closed
  • One width (~400 px) for all tabs, so windows never jump

Main area mode

  • Scene mode: terminals in a band, scene above
  • Focus mode: terminals cover the scene, panel closes

Open windows

  • Each is visible or minimised (a mark on its hotbar slot)
  • Tiles by count: 1, 2, 2+1, 2×2
  • A terminal tile keeps ~80 columns: too narrow, it stacks; no room to stack, it becomes a tab

Also: closing a window never stops the agent · Esc belongs to the terminal (Claude Code uses it to interrupt) · shortcuts only work outside the terminal

How to read a pot

Five states, each with a plant, a word, a growth stage and a shape

New · proposed 2026-10-07

The beetle: one chat that sees all agents

What it is

  • One more Claude Code session, in the repo root, without a pot
  • Knows what each agent did, its status, where the whole is going
  • Read-only first; orchestrator later via the daemon

In the layout

  • Hotbar slot 0, or key 0
  • Opens maximised (Focus this)
  • Then an ordinary window: beside an agent, minimise, notification

In the scene

  • A beetle carved into the table top, between the seed packets
  • Emissive glow shows its state: dim, pulse, red when it waits
  • The table grows: pots at the back, packets and carving in front

Should-have, decided at the end of week 2. Needed from day one: an agent may have no pot. Wireframes S17–S19 in concept/v3_layout.html.
