# gitspore: main concept

The current concept. The `v<n>_*.md` files are earlier versions and input for this one.

## Core idea

gitspore visualizes a git repo and the activity on it, and you can interact with the repo from the visualization. For example, you click an agent beetle and a terminal opens.

gitspore is multiplayer in nature, not because it has multiplayer features, but because git is multiplayer.
